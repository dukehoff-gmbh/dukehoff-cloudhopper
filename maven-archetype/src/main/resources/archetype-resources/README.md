The build writes the deployment to `target/deployment/<target>/`, next to the artifact it uploads
(`target/${artifactId}-${version}-<target>.jar` or `.zip`; for `springboot-http`, `knative` and
`scaleway-terraform` the executable Spring Boot jar).

For the Terraform targets the files from `src/main/resources/deployment/<target>/` (provider, backend,
variables) are copied there as well, so you can run Terraform in that folder:

```bash
cd target/deployment/<target>
terraform init
terraform apply
```

#if($includeTerraformProfile == 'true')
Or let Maven run it (the target profile and `deploy-with-terraform` together):

```bash
mvn verify -P<target>,deploy-with-terraform -Dterraform.command=apply
```
